## Ownership and sequence

Root owns this execution directory, shared accounts, role briefs, input pins,
coordinator scratch `.scratch/fresh-authoring-01/pilot-01/`, submission invocation,
variant materialization, freezing, integration and review disposition. Author,
recipients and reviewer own only their separately assigned attempt directories.
All work uses this checkout; no overlapping worker writes and no nested agents.
At most four agents run concurrently, including root. No Claude launch.

1. The fresh author receives only the common question, six subject files, helper
   usage, general development guidance and its saved brief. It constructs a draft
   envelope and selected support, records actual reads and stops at that checkpoint.
2. Root copies all saved regular author files into a coordinator-owned witness,
   pins exact identities, then invokes the checked helper on the copied envelope.
   The author sees the structural result, conducts one final self-check within
   its existing construction grant, saves a new final envelope and revision account,
   and stops. Root witnesses and submits that exact final selection separately.
   Any rejected input is retained and exposed; correction requires a new identity.
   This is coordinator-mediated submission, with no alteration of author bytes.
3. Root freezes the final selection, chooses and records one support omission
   before any recipient response, and materializes full, omitted and reordered
   variants. No object is silently reconstructed. Every packet includes the same
   original question and pinned subject source; its selection manifest truthfully
   identifies available and unavailable support. References do not grant reads.
4. Three fresh recipients inspect, do not execute, and save first memos/read
   ledgers. Root freezes all first responses before revealing the same selected
   support object to all three. Second memos distinguish changes in grounds from
   changes in recommendation. Original first memos remain untouched.
5. A fresh independent reviewer inspects protocol, all selections, witnesses and
   responses. Root disposes findings, reports observations and limits, and updates
   the program and current account. Unfinished work receives an explicit checkpoint.

## Witness scope and limits

The observer is root. Its witness begins before author dispatch at the timestamp
in `pilot-01/INPUTS.json`; saved draft/final files are copied after each returned
checkpoint and before the corresponding helper invocation. The witness includes
issued input copies, actual saved author files, attempted envelopes, helper
commands/streams/outcomes, selected returns, variants, frozen memos and read ledgers.
It does not observe unsaved thoughts, every intermediate edit, every tool action,
continuous source preservation, real access enforcement or execution effects.
Author read ledgers and completion/revision statements remain attributed claims.

The witness is outside worker-writable paths and initial recipient grants. Grants
are procedural; fresh contexts exclude prior conversation but ambient harness
instructions remain an influence. No working environment is deleted. Keep all
evidence through review under DEVELOPMENT.md; no pruning is authorized here.

Only standalone standard-library assembly, hashing and the existing submission
helper may execute. Use `/usr/bin/python3 -I -B`. Do not import/execute subject
code, authored checkers or proposed ledger experiments. No installed-wheel/pytest
nodes, project trials, network research, installation, custody operation or
product changes. Static predictions are not execution evidence. No new answer
schema, custody-start policy or protected-obligation change follows.

## Interpretation

ASSESSMENT.md remains fixed. Compare exact inspection dependencies, not agreement
with an expected answer. A flawed construction, missing returned support, and a
request for new execution evidence are different observations. Require an actual
inspection loss and repair before calling the omission sensitive. Report redundant
support, non-firing controls, reordered-response differences, cap pressure and
unexercised outcomes. A prompted self-check is not an unexpected finding. One
author and one reader per variant do not establish causal interface effects.
