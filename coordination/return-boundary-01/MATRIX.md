Condition names and maps stay outside recipient grants; neutral packet copies
carry their exact hashes. All recipients receive the same original question,
roles and recipe within their case. Historical role instructions are evidence,
not grants to act. No source/code/test bytes are initially supplied beyond what
the historical answer itself quotes. Current guidance is not historical evidence.
The original report+notes baseline is retained as a witness, not a fourth arm.
Both full finite candidates retain all original report/note source bytes; this
study does not measure compression or restricted authoring. The order control
changes support-unit order, not content. Replication and counterbalanced launch
order expose variation but do not estimate a population or causal format effect.

After each first response and reads are frozen, show the same original support
passage to all six recipients for that case: A3's P4 two-direction proof sketch,
A1's Finding 1 test-coverage paragraph. A separate response distinguishes new
support from renewed attention to already available support. Freeze it before
any source grant. The controls also receive the passage so that mere emphasis
is not mistaken for restored availability. Retained corroborating text can make
the omission non-firing; no claim of dispensability follows from silence.

After reviewing the named unresolved needs, select finite historical source
excerpts relevant to that purpose and give the same per-case source grant to
all recipients entering that phase. A further memo distinguishes direct source
inspection from the original auditor's account. Record unrun phases explicitly.
No historical manager review is supplied. This isolates the availability and
attribution question from agreement with a known later outcome.

Candidate dependency being tested: browsing report/prose notes in an old audit
environment can be replaced, for examining the stated answer and its basis, by
an identified finite selected return. Counterexample: a consequential stated
step remains inaccessible without unreturned auditor-created material, or the
packaging loses qualifications/attribution. Needing manager-owned pinned source
for an independent check is a different surviving connection; needing a new
execution is a new inquiry. Neither automatically warrants access to old private
scratch. Actual capture, source selection, custody, retrieval and stopping still
require operational design and qualification.

Aim to finish first responses and support restoration well before 22:00 UTC,
then reserve time for source grants if warranted, independent integration review
and an orderly checkpoint by about 22:20. Time is a scope bound, not evidence of
agent completion. Saved outputs/returns determine the observed state.
