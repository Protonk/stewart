# Smallest useful dependency comparison

Recommendation, not a dispatched study or accepted schema. This worker did not
read the A1/A3 reports or producer packets. Exact support units must therefore
come from independently reviewed producer maps; nothing below claims that a
particular proposed unit is already sufficient.

## Six first passes; preserve the option of a bounded repeat

For **each of A1 and A3**, use three fresh, isolated recipient contexts:

| Arm | Initial material | Purpose |
| --- | --- | --- |
| C: candidate with support | Candidate finite return, finite original question/context, and its named selected support. | Support-present control. Establish whether the specified reasoning/inspection task is possible under this candidate at all. |
| O: one support unit withheld | The same packet minus one coherent indispensable-or-contested support unit and all duplicate copies of that same unit. Preserve unrelated qualifications, attribution and question context. | Differing case. Test a declared content dependency without the prior pilot's broad collateral omission. |
| I: content-preserving variation | C's exact semantic units and all evidence-class qualifications, with only a chosen unit-order change. Keep specimen-internal event order and claim/qualification adjacency intact. | Invariance candidate. Separate the chosen dependency from an incidental organization change. Mechanical equality is checked independently; semantic invariance is an observation, not an assumption. |

This is **six first-pass responses**, one per cell. There is no independent
full-original arm: the retained original is used at the restoration stage.
Consequently this is a diagnostic comparison of particular candidates, not an
estimate of general format equivalence, cost or recipient error rates. Adding
an original-only arm is worthwhile only if the producer cannot justify C's
task-relevant coverage; do not silently use a poor C as the positive control.

The support-present control fires only when recipients can identify the relevant
support and perform the specified inspection with citations. If neither C nor I
can do so, O's failure does not isolate the omission. If O reconstructs the
argument anyway, record which supplied information enabled that reconstruction;
do not describe the control as missing all information. A missing-unit detection
alone is not enough: inspect what actual task or attribution changed.

If time permits, repeat the **single most consequential C/O contrast** with two
new recipients, neutral/counterbalanced packet labels and identical task words:
**eight first passes total**, not a broad additional factorial study. A single
response difference is too weak for a policy decision. Report actual completed
counts and missing cells; do not imply a scheduled repeat ran.

## Freeze each response before the next grant

1. **Return-only diagnostic pass.** Supply no project source or private scratch
   beyond the exact packet/context selection. The manager is not being asked to
   relinquish their real subject repository; this restriction measures the
   information and attribution furnished by this return. Save response and
   actual-read declaration before any further material.
2. **Restore the exact omitted unit.** Give the same verbatim unit to C, O and I,
   with the same neutral request to revise or retain their account. It is new
   information only for O; repetition in C/I controls, imperfectly, for a second
   look. Do not tell them the unit is decisive or identify an omission arm.
3. **Restore finite remaining original-return support if needed.** Use the
   reviewed producer inventory to supply a finite, predeclared set. Record
   separately what it adds beyond the targeted unit. If that set is empty,
   record no additional information rather than inventing a reveal.
4. **Restore a finite pinned subject-source selection.** Only after the earlier
   account is frozen, grant exact source members needed for checking named
   premises, preferably the same selection across arms. Separate manager-owned
   subject source from auditor scratch. A source grant can test whether a stable
   reference replaces the live audit connection. It does not require all code
   in every answer. Never provide a historical manager review as an answer key.

Stages 3/4 are conditional diagnostic grants. The coordinator may stop after a
bounded unanswered request rather than widening indefinitely. Predeclare maximum
scope and retain the original witnesses outside all candidate omissions. Where
adaptive grants differ, report the different exposure rather than pooling the
responses as if they received identical treatment. No historical code execution.

## Recipient questions, same words across arms

Ask for a short structured memorandum; allow supported finding, no supported
finding, missing evidence, unresolved premise, disagreement and reframing equally.

1. “What question and selected subject does this return address? Identify the
   answer it gives, including any limits or questions it leaves open. Cite the
   supplied locations; state any ambiguity rather than filling it in.”
2. “For each claim material to that answer, distinguish what the auditor says,
   what reasoning or specimen you can inspect here, what observation is reported
   and by whom, and what you independently checked. Explain any disagreement or
   uncertainty. You need not adopt the auditor's or any manager's conclusion.”
3. “Show one task-relevant chain from supplied support to an asserted result or
   limitation. Which steps can be assessed from these materials, and which, if
   any, require other information? Identify the smallest additional material
   needed and what seeing it could change; ‘none’ is an acceptable answer.”
4. “Which parts of your account are directly present, which are your
   reconstruction, and which remain unestablished? Would losing the auditor's
   working environment remove anything your account relies on? Distinguish that
   environment from independently retained manager subject/question material.”

At each reveal: “What, if anything, changes in your account after this material?
Name the exact new or repeated support, attribution, qualification or
counterexample. An unchanged conclusion is acceptable; say whether its basis
changed. Keep any reported execution separate from execution you observed.”

Avoid “find the omission”, “prove independence”, “is this sufficient?” without a
defined task, or any score for matching a historical judgment. Do not ask the
recipient to certify that operational custody or stopping works.

## Observations and falsifiers

Record, with locations rather than a single aggregate grade:

- Directly expressed argument versus recipient reconstruction; identified
  missing support versus unmentioned support. Silence is not evidence of private
  detection or rejection.
- Inspectable operands/specimens, internal reasoning and qualifications; whether
  a referenced target is actually present and which claim its absence affects.
- Attributed auditor/manager reports versus verified custody bytes versus
  independently checked subject facts versus unobserved execution.
- Actual request for restoration, exact material supplied and the resulting
  change or invariance. Classify origin/lifetime of each needed item.
- Available alternatives, missing evidence and reframing still expressible;
  no preferred substantive outcome built into the required fields.

The candidate's claimed independence fails for the tested task if needed
auditor-created support exists only in the omitted/disposable environment.
Reconstruction may repair the recipient's understanding while still failing
preservation of the auditor's account. Independence from manager-owned subject
source is a different, stronger claim and is not a default product requirement.
A later source check that overturns an assertion may show the return's attributed
claim was wrong while leaving its representation faithful; record both facts.

## Confounds and checks

One recipient per arm confounds recipient variation with representation. Staged
restoration adds time, repetition and learning; C/I seeing the same passage only
partly controls those. A conspicuous hole can prompt reconstruction or signal an
experimental condition. Removing repeated support across many locations may
still have collateral effects; preserve and disclose them. Reordering can alter
claim/qualification proximity, which is why this variation keeps them together.
Source familiarity, producer selection, role instructions, automatically supplied
repository guidance, search behavior and truncated tool output can affect results.
Ask recipients to record actual reads and supplied context; procedural restrictions
are not OS enforcement. Hash identity/freezing establishes retained bytes and
recorded order, not a complete independent tool-access trace.

Before dispatch, independently compare source-to-packet maps, all duplicate
instances of the omitted unit, exact neutral prompt equality, and preservation of
unrelated qualifications. Confirm C/I have identical content units and O differs
only by the declared unit; preserve any defect as a new check identity. Keep
originals and checkpoints outside candidate omissions. No product/pytest run is
required or claimed by this document comparison.

Policy decisions still required after useful readings: compulsory manager replies,
partial-work salvage and custody start/finality; the lifetime/content basis for
disposal; human handback; concrete control/delivery arrangements. Fresh authoring
and integrated custody/stop/removal tests remain separate from this matrix.
