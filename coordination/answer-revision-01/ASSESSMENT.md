# Assessment fixed before participant outputs

Root/reviewer only. This document is outside author and recipient read grants.
Assess expression, support, qualifications and inspectability, not agreement
with a preferred audit outcome or historical manager judgment. The fixed recipe
and named use are not altered to make a format look successful.

The source route has a potentially discriminating projection: the validator
retains an identity-mismatched declaration and comparison diagnostics; the
consumer emits claim values only for valid status while retaining the full
validation result in companion context. Thus a null claim value alone is not
the complete consumer observation. Missing/invalid/mismatch distinctions and
attribution must be traced through actual returned structures. This is root's
static design hypothesis, to be inspected and contested, not an answer key to
give participants. The consumer source is the deliberately withheld dependency
in two arms; comments about intended behavior cannot supply its implementation.

Record for every author/phase: available source, actual read account, selected
raw bytes and admitted snapshot, author-claimed outcome/completion, precise
supported and unresolved claims, artifacts relied upon, unselected work, and
any difficulty expressing a mixed/partial result. Classify kind from substance
separately from the common form's selected discriminator. Never invent a formal
minimal-form discriminator for the author. Record transport overhead, objects,
rejections/corrections and cap usage separately from intellectual adequacy.

Record for each recipient/phase: what claim they can repeat with qualifications,
which producer/consumer sites and distinguishing pair they can inspect, named
missing dependencies, support they had to reconstruct, and whether they can
separate original claim, source-grounded inference and observation. A request
for evidence outside the commissioned use is not automatically a return failure.
An absent author-created artifact is different from unsupplied subject source.
Keep disagreements and competing explanations attributed.

Phase transition classification: (1) new source-grounded finding, (2) correction
of prior claim, (3) formerly unresolved premise now resolved, (4) added explanation
or artifact, (5) kind/completion relabeling, (6) repetition, or a stated combination.
Compare against the complete-source repeat controls. Source arrival by itself,
or a prompt asking for a revision, is not a finding. The controlled reveal may
exercise response revision, but is not evidence of an unplanned late discovery
in ordinary investigation. Keep that remaining requirement explicit.

The gap arms should make absent consumer inspection observable if participants
respect grants; the full-source arms test the same task without that gap.
Retained scope assumptions keep the important named distinction inside the
question while excluded real enforcement questions remain legitimate limits.
The two formats have equal evidence within each schedule, but one author and
recipient per cell leave variability and presentation/transport differences as
rivals. Report concrete contrasts without causal superiority, format equivalence,
general usefulness, compression or a justified product size limit.

Preflight must verify source extraction against pinned Git, exact entry fixture
labels/identities, common-question/recipe equality, consumer absence in delayed
grants, complete-control identity, release fixed before responses, interface
instructions/limits, exclusive capture and independent witnesses. Final review
must inspect all eight selected author returns, all eight recipient memos, read/
process accounts and failed/corrected captures. A missing phase remains an explicit
limitation, never replaced with coordinator-authored content.

Output: a grounded requirements/obstructions/open-cases table with direct support
in participant returns. Distinguish requirements about content from evidence
for making a field compulsory. Preserve contradictory views. Determine readiness
for a provisional interface discussion with explicit remaining coverage, rather
than inferring that completion of this wave settles W01 or custody policy.
