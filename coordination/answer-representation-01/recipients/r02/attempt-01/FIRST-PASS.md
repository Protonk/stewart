Two qualifications materially constrain wording. First, control firing is aggregate. B014/B039's K-swap predicts the same case-level summaries when canonical fires instead of the intended strict measurement. The manual explicitly documents this limitation (context/src/stewart/resources/README.md:1269–1272). Second, equality is equality after Python JSON decoding: object key order is ignored for unique keys, arrays remain ordered, booleans differ from numbers, and raw repeated keys retain the last value (ledger.py:32–48, 134–159; README.md:1296–1315).
