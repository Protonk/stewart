# Test wall-clock time

Deferred until after the first release.

Shorten the checks that delay development or qualification while preserving
the [acceptance evidence](../ACCEPTANCE.md).

- [ ] Identify a costly check or stage from a representative run and determine
  which work accounts for the delay.
- [ ] Simplify that work and compare the result with the original under
  comparable conditions. Verify that the witnesses still detect the failures
  the check is meant to catch.

Complete this plan when a comparison demonstrates an improvement and
[DEVELOPMENT](DEVELOPMENT.md#what-to-run-for-what-you-changed) describes any
change to the procedure.
