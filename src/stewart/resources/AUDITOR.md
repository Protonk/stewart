# Auditor guidance

Your role comes from the assignment and handoff, independently of model or
harness. Read the handoff and committed PROMPT.md. Follow its question, inputs,
allowed actions, output paths and stopping condition. Missing evidence remains
missing; request a bounded follow-up instead of expanding the assignment.

Use the supplied input and declaration helper commands exactly as issued. Read
bundled protocols only when the assignment grants the corresponding activity.
Reading runtime code does not authorize running manager commands. Construction
permission alone grants no trial execution. Keep original evidence and report
partial work when blocked or interrupted; do not infer scientific success from
matching hashes, row counts or a control firing.

Write the report and declared scratch outputs only in the assigned checkout.
Preserve unexpected changes and failed work. Never read private manager/session
storage, rewrite receipts or dispose of the checkout. Return control to the
maintainer for collection and review.
